# iPad 輔具評估報告書系統 — Pilot 2.1 PDF Binding Fix

## 內容

- 報告書編號 01、05、06、16、17
- iPad 大按鈕分段填寫介面
- IndexedDB 本機個案草稿、自動儲存、搜尋、刪除
- PWA 主畫面安裝與離線快取
- 單一個案及全部個案 JSON 備份／還原
- 正式表格套印 PDF：保留衛福部空白表格頁面，將已建立座標的 checkbox、radio、select 以藍色勾號套印，並套入基本資料、評估結果及簽核資料
- 完整電子紀錄附頁：所有已填欄位一律輸出；checkbox 以 `✓`、radio 以 `●`、select 以 `▾` 標示，確保未建立正式表格座標的細項也不會遺失
- 匯出前直接從畫面重新讀取控制項狀態，避免使用者剛點選後立即匯出時讀到舊值
- 01、05、06、16、17 五份報告書合計 510 個正式表格選項座標；其餘選取值完整列於同一 PDF 的電子紀錄附頁
- 部分搭配規則與臨床提示（例如輪椅附加功能、照顧床附加功能、步行輔具高度參考）

## 部署

1. 將本資料夾完整上傳至 GitHub repository 根目錄；`index.html` 必須位於根目錄。
2. GitHub：Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save。
3. 等待 Pages 顯示網站網址，用 iPad Safari 開啟。
4. 第一次保持連線，逐一開啟主要畫面；Safari「分享」→「加入主畫面」。
5. 關閉網路後重新開啟一次，確認離線可用。

也可部署到機構管理的 HTTPS 靜態網站、Azure Static Web Apps 或其他支援 HTTPS 的靜態主機。

## 資安與使用界線

- 個案資料只存於目前瀏覽器的 IndexedDB，不會隨程式碼上傳 GitHub。
- 清除 Safari 網站資料或移除網站可能會刪除草稿；請定期匯出 JSON，並依機構規範加密保管。
- GitHub Pages 測試站請勿輸入真實個案資料。正式使用建議改採機構身分驗證、受控主機與檔案留存政策。
- 本版本為 Pilot。正式表格已套印共通基本資料、結果及簽核欄位；其餘全部內容會放入同一 PDF 的「完整電子紀錄附頁」。正式送件前仍須由評估人員逐頁覆核，並依主管機關最新規定驗證。

## 更新

若更新檔案後 iPad 仍顯示舊版：

1. 開啟網站並保持連線。
2. 關閉主畫面 App，再重新開啟。
3. 如仍未更新，移除主畫面圖示並清除該網站資料後重新加入。
